# Immas-Portfolio

Personal portfolio of Emmanuel Ugwueze, built with [Astro](https://astro.build).

All site content (projects, experience, skills) lives in `src/data/site.ts`. Project screenshots are in `src/assets/projects/`.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to dist/
firebase deploy --only hosting
```
